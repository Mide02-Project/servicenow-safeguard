## A note on counts

If you show both the manager AI overview and the Safety Manager dashboard, the corrective action numbers differ on purpose. The AI overview counts all corrective action records (pending, completed and open), while the dashboard counts open corrective actions only. The high/critical and overdue figures are separate tiles.
