## Understanding Corrective Action Counts

The Manager AI overview and Safety Manager dashboard display different corrective action figures because they use different counting scopes.

- **Manager AI overview:** Counts all corrective action records, regardless of status.
- **Open Corrective Actions:** Counts only records with Open status.
- **High/Critical Corrective Actions:** Displays actions classified as high or critical risk.
- **Overdue Corrective Actions:** Displays actions that have passed their due dates.

These figures represent different views of the same corrective action data. An action can also fall into more than one category, such as being both high-risk and overdue.
